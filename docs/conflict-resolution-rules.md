# Google Calendar 競合解決ルール

## 基本原則

1. **固定ブロック（GCalインポート）はGCal絶対優先**
   - App側での編集不可（UIでロック）
   - `is_locked: true` フラグで管理

2. **作業予定（Appエクスポート）はApp一次情報**
   - GCal側の変更は次回同期時に差分通知
   - ユーザー承認で反映

3. **削除はカスケード**
   - 固定ブロック削除時、衝突により自動分割されたタスク断片は「未割当リスト」へ戻す

## 同期フロー

```
[GCal] ──インポート──▶ [App DB] (is_locked=true)
[App]  ──エクスポート──▶ [GCal]  (gcal_event_id 付与)
```

## 競合検出

- タイムライン配置時、固定ブロックとの重複を検出
- 重複がある場合はエラー表示、自動分割は行わない（Phase 2 で検討）

## 未確定事項
